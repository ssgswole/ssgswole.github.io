# Snuggle Stories website

Static marketing site for [Snuggle Stories](https://ssgswole.github.io/snuggle-stories/), served by GitHub Pages.
No trackers, analytics or cookies.

- `index.html`: landing page
- `privacy.html`: privacy policy (fill in the contact email placeholder `[your email]`)
- `flyer.pdf`: printable letter-size flyer with QR code
